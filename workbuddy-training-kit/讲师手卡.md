# WorkBuddy 分享会讲师手卡 v2

## 开场定位

建议开场这样说：

“今天不是负责人专场，也不是软件菜单培训。我们面向隧桥院所有同事，先把 WorkBuddy 是什么、怎么装、怎么用讲清楚，再用四个隧桥院日常工作场景演示它能做到什么。大家不需要今天就成为 AI 高手，但至少要知道明天可以把哪件重复工作交给它试一次。”

## 讲课主线

1. 先破除“就这”的预期：如果只让 AI 写几段话，确实没意思。
2. 说明 WorkBuddy 的形态：工作空间 + 任务执行 + 文件产物 + 连接器。
3. 带新手完成第一步：下载、登录、工作空间、首个任务。
4. 展示飞书联动思路：连接器/助理，不强求现场全部配置。
5. 用四个实战拉开想象力：合同、项目、人员、PPT。
6. 让学员跟做，最后写自己的第一个真实任务。

## 时间压缩策略

如果 90 分钟：按 `培训方案总览.md` 完整讲。

如果 60 分钟：少讲菜单，多讲闭环。

- 安装配置只讲关键路径，不现场等所有人装完。
- 飞书联动只讲概念和一次演示，不组织全员扫码。
- 四个案例重点跑 A 和 B，C 和 D 讲操作路径和提示词。
- 动手环节至少留 8 分钟，不然大家只会“听懂但不会用”。

## Slide 讲法提示

### 01-03 开场

重点是把听众拉进来：今天不是 AI 概念课，而是办公工作方式课。

可提问：

- “你最近一次花半天整理的材料是什么？”
- “有没有哪类表格每个月都要重复做？”
- “哪些周报/会议纪要让你觉得机械重复？”

### 04-06 形态与路径

不要讲太多技术词。只讲三个关键词：

- 工作空间：它能围绕文件夹干活。
- 产物：它能生成可打开的文件。
- 连接器：它能在授权范围内联动办公平台。

### 07-09 入门

这部分要照顾第一次接触的同事。

建议现场演示：

```text
请在当前工作空间生成一个 Excel 表格，列出我本周的工作计划。
字段包括：日期、工作内容、优先级、预计耗时、完成状态。
```

演示时一定要打开产物文件，让大家看到结果在哪里。

### 10-11 飞书联动

讲清楚两件事：

- 连接器：在授权范围内读办公资料。
- 助理：通过即时通讯工具远程触发电脑上的 WorkBuddy。

如果现场授权顺利，演示真实飞书周报读取；如果不顺，立刻切换：

```text
请读取 sample-data/飞书周报碎片样例.csv 和 sample-data/项目基础信息.csv，生成项目状态看板。
```

### 12-16 四个演练

每个演练只讲四个问题：

- 目标是什么？
- 输入材料是什么？
- AI 要做哪几步？
- 输出物怎么验收？

不要把案例讲成纯展示，要不断提醒“这就是你们可以拿走改造的任务卡”。

### 17-18 动手与追问

提醒大家：第一版不完美很正常。

现场统一要求每个人至少追问一次：

```text
请解释你的字段识别、计算公式、异常阈值和证据行。
```

或：

```text
请把结论压缩成 3 条，适合部门例会 1 分钟讲完。
```

### 19 安全与复核

不要回避安全问题。建议明确说：

“AI 可以帮我们做第一版、做归拢、做检查，但正式报告、经营数据、涉密资料必须按单位要求复核和授权。”

### 20-21 课后落地

把大家从“今天觉得好玩”拉回“明天怎么用”。

要求每个人写下：

- 数据来源。
- 想让它做什么。
- 输出给谁看。
- 怎么复核。

## 四个演练的优先级

若时间紧：

1. A 经营合同分析：最容易体现“跨表 + 规则 + 预警”。
2. B 项目状态汇总：最容易体现“飞书周报 + 风险归拢”。
3. D 周报转 PPT：最容易让普通同事立刻上手。
4. C 人员工作量评估：适合管理层讨论，但现场容易引发口径争议，可作为进阶。

## 现场故障预案

| 问题 | 处理 |
| --- | --- |
| 有人没安装 | 让他先看同桌或投屏，课后按指导书安装。 |
| 飞书授权失败 | 用本地样例数据替代，不中断培训。 |
| 结果不准 | 要求 WorkBuddy 先解释字段和口径，再修正。 |
| 任务太慢 | 拆成三步：读字段、算指标、生成报告。 |
| 学员不知道问什么 | 让他从学员任务卡复制一个任务。 |

## 结束语参考

“今天最重要的不是记住 WorkBuddy 有多少功能，而是知道我们可以把重复的信息整理工作，变成可描述、可执行、可复核的任务。下一步建议大家从一个小任务开始，先让它帮你做第一版，再通过追问把它调成你的工作口径。”
