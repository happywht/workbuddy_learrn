# WorkBuddy 分享会培训方案总览 v2

## 重新定位

这场培训不应只面向负责人，而应定位为：

> 面向隧桥院全体同事的一次 WorkBuddy 入门分享会 + 实战工作坊。

因此内容需要同时满足四类人：

- 第一次接触 AI 办公工具的同事：要知道是什么、怎么装、怎么发第一个任务。
- 普通设计人员：要看到周报、纪要、表格、PPT 等日常场景。
- 项目负责人：要看到项目状态、风险、人员投入如何归拢。
- 经营和管理人员：要看到合同、回款、台账、汇报如何落地。

## 核心思路

不要把 WorkBuddy 讲成“更聪明的聊天软件”，也不要只讲负责人案例。更好的主线是：

1. 它是什么形态：AI 办公工作台，能围绕工作空间执行任务。
2. 怎么开始用：下载安装、登录、工作空间、首个任务、产物查看。
3. 怎么和办公系统联动：连接器、飞书、多维表格、助理。
4. 怎么做真实工作：经营合同、项目状态、人员负载、周报转 PPT。
5. 怎么沉淀到部门：固定任务卡和人工复核机制。

## 为什么不能只放原 31 页 PPT

原 PPT 的优点是功能覆盖完整，适合作为课后说明书；但如果现场逐页讲，普通同事容易觉得离自己远，负责人也会觉得缺少可落地流程。

本次 v2 方案保留功能入门，但把重点改成：

- 前置铺垫更完整：让新手知道怎么装、怎么配置、怎么开始。
- 场景更开阔：个人、项目、经营、管理都能找到入口。
- 案例更项目化：每个演练都有目标、输入、步骤、输出和提示词。
- 现场更稳：飞书联动可演示，但授权不稳定时有本地样例替代。

## 推荐时长

### 90 分钟版本

| 时间 | 内容 |
| --- | --- |
| 0-10 分 | 开场：为什么不是“就这”，WorkBuddy 到底是什么。 |
| 10-25 分 | 入门：下载安装、工作空间、首个任务、产物查看。 |
| 25-35 分 | 飞书联动：连接器、助理、真实演示与备用方案。 |
| 35-65 分 | 四个实战：A 合同、B 项目、C 人员、D PPT。 |
| 65-85 分 | 学员跟做：每人选一个任务卡跑通并追问一次。 |
| 85-90 分 | 收束：写下自己的第一个真实任务。 |

### 60 分钟版本

| 时间 | 内容 |
| --- | --- |
| 0-8 分 | 开场与定位。 |
| 8-18 分 | 入门与首个任务。 |
| 18-26 分 | 飞书联动讲解，不强求全员配置。 |
| 26-42 分 | 重点演示 A 经营合同 + B 项目状态。 |
| 42-52 分 | 快速讲 C 人员负载 + D 周报转 PPT。 |
| 52-60 分 | 学员复制一个任务卡，跑通或至少完成任务描述。 |

## 材料结构

- `index.html`：投屏主材料，22 页。
- `入门安装与飞书联动指导书.md`：适合第一次接触的同事课前/课后看。
- `四个实战演练操作手册.md`：四个项目化演练的详细步骤。
- `学员任务卡.md`：现场复制即可用的任务卡。
- `提示词清单.md`：追问、复核、压缩、换受众常用提示词。
- `sample-data/`：脱敏样例数据，支持全部演练。

## 现场建议

1. 开场先让大家说一个“最想交给 AI 的重复工作”。
2. 不要在安装和扫码授权上拖太久，提前准备安装包和本地样例。
3. 飞书联动要讲，但授权失败时立刻切换本地样例。
4. 每个案例都要强调“人工复核”，避免让大家误以为 AI 可以直接替代专业判断。
5. 课后收集真实任务，形成隧桥院自己的任务卡库。

## 能避免“就这就这”的关键

不要只展示“生成一段文字”。要展示：

- 它能读取多文件。
- 它能跨表关联。
- 它能生成预警规则。
- 它能保留证据行。
- 它能输出可编辑文件。
- 它能通过追问变成符合单位口径的成果。
