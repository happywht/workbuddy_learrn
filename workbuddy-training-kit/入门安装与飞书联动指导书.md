# WorkBuddy 入门安装与飞书联动指导书

> 适用对象：第一次接触 WorkBuddy 的同事、想在培训现场跟做的同事、需要课后自行配置的同事。

## 1. 先理解 WorkBuddy 是什么

WorkBuddy 可以理解为“装在电脑上的 AI 办公工作台”。它和普通聊天 AI 最大的区别，不是回答更漂亮，而是能围绕你的工作空间执行任务：读取文件、整理表格、生成报告、制作 PPT、调用授权的办公连接器，并把结果保存成可验收的文件。

一句话：

> 普通 AI 更像顾问，WorkBuddy 更像能在你电脑上干活的助理。

## 2. 适合用它做什么

适合：

- 把一堆 Excel 汇总成分析表和异常清单。
- 从周报、纪要、飞书文档里提取项目进展和风险。
- 把 Markdown、Word、会议纪要转成汇报提纲或 PPT。
- 批量整理文件、改格式、分类归档。
- 做第一版材料，再通过追问持续修改。

暂不建议直接交给它：

- 涉密或敏感资料，除非单位已有明确授权和安全边界。
- 最终报出文件，未经人工复核不要直接使用。
- 口径不清的数据统计，先让它列出字段、口径和疑问。

## 3. 下载与安装

以官方最新页面为准：

- 产品页：https://www.codebuddy.cn/work/
- 快速开始：https://www.codebuddy.cn/docs/workbuddy/Quickstart
- Windows 安装指南：https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide

Windows 基本要求：

- Windows 10 及以上。
- 建议提前关闭不必要的安全拦截弹窗。
- 网络可访问官方下载页面和单位办公平台。

安装步骤：

1. 打开官方页面，下载 WorkBuddy 安装包。
2. 双击安装包，按向导安装。
3. 建议保留默认安装路径，并勾选创建桌面快捷方式。
4. 安装完成后启动 WorkBuddy。
5. 按单位账号或产品要求登录。

## 4. 第一次启动后先做三件事

### 4.1 设置工作空间

工作空间就是 WorkBuddy 优先读写文件的文件夹。建议不要直接选整个桌面或整个硬盘，而是按任务建一个培训目录。

建议结构：

```text
D:\WorkBuddy练习\
├── A-经营合同分析\
├── B-项目状态汇总\
├── C-人员工作量评估\
└── D-周报转PPT\
```

培训现场可以直接选择本资料包的目录：

```text
workbuddy-training-kit
```

### 4.2 发起第一个任务

先用一个很小的任务确认它能正常工作：

```text
请在当前工作空间生成一个 Excel 表格，列出我本周的工作计划。
字段包括：日期、工作内容、优先级、预计耗时、完成状态。
```

你需要观察三件事：

- 它是否理解了任务。
- 它是否创建了文件。
- 结果文件在哪里查看和打开。

### 4.3 学会看结果区

重点看：

- 生成了哪些文件。
- 文件保存在哪个目录。
- 执行过程中有没有需要确认的操作。
- 能不能继续追问修改。

## 5. 如何写一个可执行任务

不要只写：

```text
帮我分析一下这个表。
```

建议写成：

```text
请分析 sample-data/经营合同与回款样例.xlsx。
按部门统计合同额、已回款、未回款、回款率；
标出回款率低于 60% 或逾期超过 30 天的合同；
输出为 Excel，并生成一段适合部门例会汇报的管理摘要。
```

通用公式：

```text
我要你做什么 + 数据在哪里 + 按什么口径 + 输出什么形式 + 给谁看
```

## 6. 飞书联动应该怎么理解

飞书相关能力不要混成一个概念。建议按两类讲：

### 6.1 连接器：让 WorkBuddy 访问授权的办公数据

连接器的价值是：让 WorkBuddy 不只处理本地文件，也能在授权范围内读取或处理办公平台里的内容，例如文档、表格、消息或其他系统数据。

现场讲法：

> 如果连接器可用，AI 就不用等你把文件下载下来；它可以在授权边界内直接读取资料，再生成汇总结果。

注意：不同版本、单位权限、管理员配置会影响可用连接器。培训现场应以实际客户端显示为准。

### 6.2 助理：通过飞书等即时通讯工具远程触发电脑上的 WorkBuddy

官方文档中，“助理”是远程控制功能。简单说，就是你在手机或即时通讯工具里发任务，电脑上的 WorkBuddy 执行，执行完成后返回结果。

适合场景：

- 会议中临时让电脑整理纪要。
- 外出时让电脑处理指定文件夹。
- 通过群或个人消息触发固定任务。

注意：助理配置通常涉及应用、权限、扫码或管理员配置，培训现场可以演示概念，不建议把所有人都卡在配置环节。

## 7. 飞书联动演示建议

如果现场权限稳定，演示：

```text
请读取我有权限访问的飞书周报文档，提取本周项目进展、风险和下周计划，整理成项目状态汇总表。
```

如果现场权限不稳定，改成本地替代演示：

```text
请读取 sample-data/飞书周报碎片样例.csv 和 sample-data/项目基础信息.csv，
按项目汇总本周进展、风险问题和下周计划，输出项目状态看板。
```

讲师提示：

- 飞书联动是加分项，不要让授权问题拖垮主课。
- 先用本地样例展示“能产出什么”，再说明真实环境下可以替换为飞书连接器。
- 所有授权都要按单位要求执行。

## 8. 新手最容易踩的坑

| 问题 | 处理方式 |
| --- | --- |
| 任务太泛 | 补充数据来源、口径、输出格式。 |
| 找不到文件 | 把文件放进工作空间，或在任务里写清楚路径。 |
| 结果不准 | 让它先列字段识别、计算公式和疑问。 |
| 生成内容太长 | 指定页数、条数、汇报对象。 |
| 连接器授权失败 | 先用本地样例演示，课后再配置。 |
| 担心安全 | 只用脱敏数据，正式成果人工复核。 |

## 9. 课后建议

第一周不要追求高级自动化，先完成三件事：

1. 用 WorkBuddy 处理一次真实 Excel。
2. 用 WorkBuddy 整理一次会议纪要或周报。
3. 把一个常用任务写成固定提示词，保存下来反复用。
