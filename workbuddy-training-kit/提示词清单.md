# WorkBuddy 提示词清单

## 通用开场

```text
请先不要直接生成最终文件。请先说明你理解的任务目标、数据来源、输出格式和可能需要我确认的问题。
```

```text
请先列出你将采用的处理步骤。我确认后再执行。
```

## 数据分析

```text
请先识别这个表格的字段含义，并指出哪些字段可能需要人工确认。
```

```text
请按部门/项目/负责人汇总数据，并把计算口径写在结果表顶部。
```

```text
请把异常项单独列成清单，包含异常原因、涉及金额或进度、建议处理动作。
```

## 报告和汇报材料

```text
请把结果改写成给部门负责人看的管理摘要。先讲结论，再讲证据，最后讲动作。
```

```text
请把这份内容整理成 5 页以内的汇报提纲。每页包含标题、核心结论和不超过 3 个要点。
```

```text
请把语气改得更正式，但不要写空话，所有结论都要对应到数据或事实。
```

## 项目管理

```text
请从这些周报中提取项目名称、负责人、计划进度、实际进度、风险、下一步动作，并生成项目状态表。
```

```text
请找出需要本周协调的事项，按紧急程度排序，并建议由谁跟进。
```

```text
请把风险项目分成进度风险、成本风险、外部协调风险和质量风险四类。
```

## 人员负载

```text
请按人员汇总各项目投入比例，标出总投入超过 100% 的人员和低于 60% 的人员。
```

```text
请根据当前负载，给出新增项目的人员安排建议，并说明理由。
```

## 结果复核

```text
请解释你生成结果中的关键计算公式，并列出你引用了哪些原始数据行。
```

```text
请检查结果中是否存在明显矛盾、缺失值或异常值，并生成复核清单。
```

```text
请把刚才的结果压缩成 3 条最重要结论，适合在部门例会上 1 分钟讲完。
```
