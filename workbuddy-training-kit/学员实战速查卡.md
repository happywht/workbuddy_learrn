# WorkBuddy 实战速查 / 实操指引卡

## 第一部分：准备工作

### 1. 下载安装

访问：

```text
https://www.codebuddy.cn/work/
```

备用入口：

```text
https://www.codebuddy.cn/work/
https://www.codebuddy.cn/docs/workbuddy/Quickstart
```

安装后打开 WorkBuddy，按提示登录企业账号。

### 2. 设置工作空间

建议本次培训选择资料包目录：

```text
workbuddy-training-kit
```

不要第一次就选择整个硬盘。工作空间越清晰，任务越容易执行和复核。

### 3. 飞书授权

首次连接飞书等办公平台时，通常需要扫码授权。请提前确保：

- 已安装并登录飞书客户端。
- 网络可访问企业办公平台。
- 当前账号有对应文档或多维表格权限。

如果现场授权失败，不影响学习。先用 `sample-data` 本地样例完成练习。

## 第二部分：核心能力速览

WorkBuddy 的价值不是“帮我写一段话”，而是：

- 读取文件和表格。
- 理解业务口径。
- 拆解任务步骤。
- 生成可编辑成果。
- 支持追问修改。
- 与飞书等办公系统联动。

通用任务公式：

```text
我要你做什么 + 数据在哪里 + 按什么口径 + 输出什么形式 + 给谁看
```

## 第三部分：今日跟做任务

### 入门任务：生成一个工作计划表

```text
请在当前工作空间生成一个 Excel 表格，列出我本周的工作计划。

字段包括：
日期、工作内容、优先级、预计耗时、完成状态。

要求：
1. 输出为 .xlsx 文件
2. 表头清晰
3. 给出保存路径
```

追问：

```text
请把优先级改成“高/中/低”下拉选项，并增加一列“是否需要他人协助”。
```

## 第四部分：四大实战指令

### A. 经营合同分析

样例文件：

```text
sample-data/经营合同与回款样例.xlsx
```

指令：

```text
请分析 sample-data/经营合同与回款样例.xlsx。

目标：从合同主表、回款流水和客户信用等级中生成异常账款预警清单。

请先识别每个工作表的字段含义，说明统计口径；
再按合同号汇总已回款金额和最近回款日；
根据签约日期和账期天数计算应回款截止日；
计算回款率、剩余应收、逾期天数；
按红色高危、黄色中危、蓝色关注、正常生成预警等级；
输出 Excel：预警清单、部门汇总、客户风险汇总、管理摘要。

请先列出字段和计算口径，我确认后再生成最终文件。
```

### B. 项目状态汇总

样例文件：

```text
sample-data/飞书周报碎片样例.csv
sample-data/项目基础信息.csv
```

指令：

```text
请读取 sample-data/飞书周报碎片样例.csv 和 sample-data/项目基础信息.csv。

目标：把碎片化周报整理成统一的项目状态看板。

请输出：
1. 项目状态汇总表：项目名称、项目经理、计划进度、估算实际进度、本周进展、Top3风险、下周关键动作。
2. 风险状态评级：高、中、低，并说明评级依据。
3. 进度滞后项目清单：实际进度低于计划进度10个百分点以上。
4. 需要院/部门协调的事项清单。

请保留关键原文证据，方便人工复核。
```

### C. 人员工作量评估

样例文件：

```text
sample-data/任务工时样例.csv
sample-data/工时填报样例.csv
sample-data/人员投入样例.csv
```

指令：

```text
请分析 sample-data/任务工时样例.csv、sample-data/工时填报样例.csv 和 sample-data/人员投入样例.csv。

目标：生成团队成员工作量评估和产能热力图。

请输出：
1. 每人任务实际工时、填报工时、偏差率。
2. 每人当前项目投入比例汇总。
3. 过载人员、可承接人员、填报异常人员清单。
4. 人员 × 日期热力图数据表。
5. 人员 × 项目投入矩阵。
6. 面向项目负责人的任务调整建议。

请先列出你采用的统计口径和异常阈值。
```

### D. 周报转汇报 PPT

样例文件：

```text
sample-data/周报转PPT样例.md
```

指令：

```text
请读取 sample-data/周报转PPT样例.md。

目标：生成一份6页以内的部门例会汇报PPT大纲。

要求：
1. 面向隧桥院全体或部门负责人，语言要清楚直接。
2. 页面结构建议：封面、总体进展、重点项目、风险与协调事项、下周计划、需要决策的问题。
3. 每页标题要是结论句，不要只写“项目情况”。
4. 每页不超过3个要点。
5. 先输出PPT大纲，我确认后再生成PPT文件。
```

## 第五部分：通用追问

结果不理想时，不要马上重做。先追问：

```text
请解释你采用的字段、公式、异常阈值和证据行。
```

```text
请列出哪些地方需要人工复核，哪些结论不能直接用于正式报告。
```

```text
请把结果压缩成3条最重要结论，适合部门例会1分钟讲完。
```

## 第六部分：安全提醒

- 培训现场优先使用脱敏样例数据。
- 涉密资料和敏感经营数据必须按单位要求处理。
- 连接器授权范围要确认清楚。
- WorkBuddy 是 Copilot，负责辅助整理和生成初稿；最终判断和正式报送仍由人负责。
