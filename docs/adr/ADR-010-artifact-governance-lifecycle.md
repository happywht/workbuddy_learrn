# ADR-010：案例版本与发布后治理

- 状态：Accepted
- 日期：2026-08-08

## 决策

1. 案例版本不可变；更新必须创建新的预览，经过同一套扫描、范围授权和明确确认后写入 `artifact_version`。
2. 报告不引入事前编辑审核。可见案例被报告后进入 `reported` 隐藏状态，保留报告原因和审计；所有读取接口只返回 `published`。
3. Artifact owner 可以明确确认后从已有不可变版本回滚，恢复 `published` 状态；回滚不会删除新版本或审计历史。
4. 评分和报告均使用幂等键，以追加审计事件作为 PoC 持久化；真实规模化部署时再拆分查询模型，不改变审计事件语义。

## 结果

版本、报告、评分和回滚 REST/MCP 契约已有本地实现与测试。组织管理员角色、报告复核队列、通知和跨组织治理仍需真实 IdP/运营流程确认，不能把 `reported` 状态当作人工审核结论。
