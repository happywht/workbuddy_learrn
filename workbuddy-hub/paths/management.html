Path 03 / Management

先让资料把问题指出来，再由人决定怎么交付

这条学习线围绕经营和项目管理中的两类检查：一项识别合同回款风险，另一项对照交付清单检查项目资料、版本与校审闭环。

适用对象经营、计划与管理人员
单项用时15-20 分钟
决策边界AI 找异常，人确认口径与行动
01 了解02 学习03 使用04 验收
合同、财务和项目成果资料都应在受控工作空间中处理。培训只使用合成样例，真实使用前请确认数据范围和交付用途。
01 / 了解

管理分析的价值不在“生成一张表”，而在口径可追溯

WorkBuddy 可以快速清洗、关联和计算，但经营判断不能建立在隐藏公式或模糊阈值上。一个可用的管理成果，必须同时给出结论、计算口径、原始证据和待确认事项。

RULE先定义交付口径成果类别、版本规则和必交文件必须明确。
EVIDENCE再保留来源每个缺项或冲突都回到清单、目录、校审或会议纪要。
DECISION最后由人确认AI 负责发现和整理，是否补充、修改或交付仍由项目人员决定。
02 / 学习

两项练习共用同一套数据纪律

先检查主键、时间和单位，再做关联计算。任何无法匹配的记录都应单列，而不是强行合并。

01确认主键合同用合同号关联，人员数据用姓名或唯一标识关联；别名要先建立映射。
02确认时间明确报告基准日或评估周期，避免同一指标跨不同时间段比较。
03确认单位金额、天数、小时和投入比例保持统一，空值与零值要区分。
04确认阈值用途预警用于提醒和复核，不直接等同于责任认定、绩效结论或资源调整命令。
培训规则：下面所有文件都是合成样例。迁移到真实业务数据时，应单独建立受控工作空间，并按单位要求处理合同、财务和人员信息。
03 / 使用

选择一项管理任务完成实战

两项练习彼此独立。先跑与你当前工作最相关的一项，不要求一次把两个都做完。

01识别与清洗确认合同号、金额、签约日期、账期和回款记录，单列无法匹配项。
02计算截止日应回款截止日 = 签约日期 + 账期天数；复杂条款必须人工确认。
03汇总回款按合同号计算已回款总额、最近回款日、回款率和剩余应收。
04应用预警规则按明确阈值生成红、黄、蓝、正常等级，同时保留触发原因。
05输出与复核生成预警清单和管理摘要，高风险记录回到合同与回款证据。
请分析工作空间中的 `经营合同与回款样例.xlsx`。目标：从合同主表、回款流水和客户信用等级中生成异常账款预警清单。请先识别每个工作表的字段含义，说明统计口径，并向我确认报告基准日。确认后： 1. 按合同号汇总已回款金额和最近回款日； 2. 根据签约日期和账期天数计算应回款截止日； 3. 计算回款率、剩余应收、逾期天数； 4. 按“逾期超过90天或回款率低于30%=红色高危；逾期31-90天或回款率30%-60%=黄色中危；逾期1-30天或回款率60%-80%=蓝色关注；无逾期且回款率不低于80%=正常”分级； 5. 输出 Excel，包含预警清单、部门汇总、客户风险汇总和管理摘要； 6. 每条风险保留原始证据行和人工复核提示。

验算

  • 基准日与账期口径是否一致
  • 回款是否按合同号正确汇总
  • 逾期天数和回款率抽样重算
  • 空值、作废合同是否正确处理

决策复核

  • 高风险是否有原始证据
  • 信用等级是否只作辅助参考
  • 建议动作是否需要负责人确认
  • 正式成果是否允许包含客户信息

请作为项目成果交付检查助手，分析工作空间中的 `项目成果交付清单.csv`、`项目资料目录.csv` 和 `校审与会议纪要.md`。 请完成以下工作： 1. 建立实际资料目录，识别成果类别、版本号和修改时间； 2. 将实际文件与交付清单逐项匹配，标记已找到、缺失、疑似重复、版本冲突和需要人工确认； 3. 从校审意见和会议纪要中提取尚未明确闭环的事项； 4. 检查文件名称、版本号和目录记录之间的不一致； 5. 输出项目成果交付检查报告和交付前待确认清单； 6. 无法确认的内容保留原文依据，不要擅自判断项目是否可以最终交付。

检查复核

  • 清单中的成果类别是否覆盖本次交付
  • 版本号和修改时间是否能够互相印证
  • 缺失项是否只是文件命名差异
  • 每个问题是否保留来源文件

交付边界

  • 文件名不能替代成果内容审查
  • 疑似冲突必须由项目人员确认
  • 校审意见要确认是否真正闭环
  • AI 不直接判断项目是否可以交付
04 / 验收

正式使用前，依次检查公式、证据和用途

管理分析不能只看结果表是否整齐。至少抽查一条正常记录和一条异常记录，并确认阈值适用于当前管理目的。

数据与计算

  • 主键、时间周期和单位已经统一
  • 截止日、回款率或偏差率可以手工复算
  • 空值、零值和无法匹配记录被单独处理
  • 每条异常都能回到原始记录

用途与决策

  • 预警只用于提醒，不直接认定责任
  • 工作量结果不直接等同于绩效
  • 建议动作考虑专业能力和项目连续性
  • 真实数据的查看、保存和外发范围已确认
任何无法解释的高风险记录，都应进入“待人工确认”清单，而不是被自动修正或隐藏。
