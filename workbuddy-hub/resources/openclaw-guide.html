01 / 是什么

从"会聊天"到"会干活"

OpenClaw 是一款开源、本地优先的个人 AI 助手与自主代理（AI Agent）框架，基于 TypeScript 开发，由开发者 Peter Steinberger 于 2025 年 11 月推出。它的项目图标是一只龙虾，因此在技术社区里被亲切地叫做"龙虾"或"小龙虾"（曾用名 Clawdbot、Moltbot）。

和 ChatGPT 这类"只能回答问题"的聊天工具不同，OpenClaw 的定位是"真正能干活"——它能理解你的意图，并自主去操作软件、读写文件、控制浏览器、执行脚本，把一件多步骤的工作真正做完。这也是它常被称作"数字员工"的原因。

关键词 01开源框架源代码完全开放，可自由审阅、修改和扩展，社区驱动迭代。
关键词 02本地优先运行在你自己的设备或服务器上，数据不经第三方云，隐私可控。
关键词 03自主执行不止于对话，能动手完成文件、网页、脚本层面的多步骤任务。
为什么是"龙虾"？ 这是 OpenClaw 项目图标带来的昵称。对我们这类对数据安全要求较高的单位而言，它最值得关注的不是图标，而是"本地优先、数据自有"的理念——这也是后续判断它适合什么场景的关键。
02 / 核心能力

六项关键能力一览

OpenClaw 把大模型与本地操作系统、浏览器、通讯工具连接起来，构成一个能持续工作的 Agent。下面是它最常被提到的六项能力。

能力 01多渠道接入接入 WhatsApp、Telegram、Discord、Slack 等通讯平台，在熟悉的聊天界面里直接下指令。
能力 02浏览器控制自动打开网页、填写表单、抓取和整理信息，把重复的网上操作交给它。
能力 03文件与系统操作读写本地文件、执行脚本、调用接口，完成本机层面的自动化。
能力 04多模型协作可接入 Claude、GPT、Gemini，也能通过 Ollama 等接入本地模型，按任务选合适的模型。
能力 05持久记忆用 Markdown 文件留存上下文，没有隐藏状态，记忆透明、可审计、可管理。
能力 06技能扩展通过 Skills 插件增加能力，并支持多个 Agent 分工协作，处理更复杂的工作流。
能力越强，边界越重要。 OpenClaw 拥有系统级执行权限，意味着它能把事做完，也意味着必须在受控环境或隔离设备上运行，并在关键步骤保留人工确认。这和本学习中心一直强调的"安全红线"是一回事。
03 / 对比 WorkBuddy

OpenClaw 与 WorkBuddy，怎么选

OpenClaw 和 WorkBuddy 都是"操作型"AI，但定位很不一样。理解这条线，能帮你判断该在什么场景用谁。

对比维度OpenClawWorkBuddy
部署方式本地 / 服务器自托管云端，开箱即用
数据归属完全本地，不经第三方云云端处理（涉密资料需先脱敏）
上手门槛较高，需部署与配置零门槛，安装即用
擅长场景系统级自动化、定时任务、多通道集成办公文档、Excel、PPT、飞书协同
适合人群技术团队、数据敏感场景全员日常办公提效
模型选择自选，支持本地模型内置云端模型

提示：在窄屏设备上可以左右滑动查看完整对比表。

一句话建议

日常办公交付（报表、PPT、飞书协同）——用 WorkBuddy，全员可用、即装即用。
数据必须本地化、要做系统级深度自动化——值得让技术团队研究 OpenClaw。
两者并不冲突：WorkBuddy 解决"人人能用"的办公提效，OpenClaw 代表"数据自主、深度自动化"的前沿方向，可作为实验室的探索课题。
